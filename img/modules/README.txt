MTM – Modul-/Kachelbilder
=========================

Lade die echten MTM-Fotos in DIESEN Ordner (img/modules/) und benenne
sie GENAU so wie unten. Dann erscheinen sie automatisch im Kachel-Grid,
ohne dass am Code etwas geaendert werden muss.

Empfohlen: Hochformat ca. 3:4, ca. 600x800 px, .jpg

  cantronic.jpg            -> M, F, V, S-Cantronic (CAN-Bus Optimierung)
  antriebstechnik.jpg      -> Antriebstechnik
  abgasanlagen.jpg         -> Abgasanlagen
  entwicklung.jpg          -> Entwicklung
  bimoto-felgen.jpg        -> Bimoto Felgen
  nardo-felge.jpg          -> Nardo Felge
  fahrwerke.jpg            -> Fahrwerke
  bremsanlagen.jpg         -> Bremsanlagen
  wartung-reparatur.jpg    -> Wartung & Reparatur
  individual.jpg           -> Individual
  leistungssteigerung.jpg  -> Leistungssteigerung
  teilegutachten.jpg       -> Teilegutachten

Solange ein Bild fehlt, zeigt die Kachel einen dezenten dunklen
Hintergrund - nichts wirkt "kaputt".
